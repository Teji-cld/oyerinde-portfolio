# Oyerinde Portfolio

A React + Vite personal portfolio focused on Cloud & Backend Engineering.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Build

```bash
npm run build
```

## Before deploying

Update the following placeholders:

- GitHub links in `src/App.jsx` and `src/data/projects.js`
- LinkedIn link in `src/App.jsx`
- Email in `src/App.jsx`
- Project screenshots in `public/images/`
- Project live-demo URLs in `src/data/projects.js`

## Design

The visual system uses:

- Graphite-navy background
- Slate structural accent
- Copper signal accent
- IBM Plex Sans + IBM Plex Mono
- Instrumentation-inspired Response Curve
- Architecture diagrams built from the actual project flows

## Deploy

This project is designed to work with Vercel. Connect the GitHub repository to Vercel and deploy.
